초기 설정 순서

IP는 예시예요. 공유기 대역에 맞춰 바꾸면 돼요.

1

네트워크

  • 데모용 공유기 하나, 2.4GHz 켜기, WPA2-PSK(AES)
  • 아이폰 핫스팟이면 '호환성 최대화' 켜기
  • DHCP 예약: PC .10, 라즈베리파이 .11, ESP32 .20
2

PC 허브

  • 네트워크 프로필을 '개인'으로
  • 방화벽 인바운드 TCP 5000(웹), 5001(ESP32) 허용
  • 설정 파일: Transport=Tcp, 백업 COM 포트
3

ESP32

  • 첫 업로드만 USB (WiFiManager + OTA 포함)
  • 폰으로 SmartHome-Setup AP 접속 → SSID, 비번, PC IP 입력
  • 이후 펌웨어는 OTA(무선)로 업로드
  • 아날로그 입력은 ADC1 핀(GPIO32~39), 5V 어댑터 따로
4

라즈베리파이 · 휴대폰

  • 같은 공유기에 접속
  • 라즈베리파이 설정 파일에 http://PC-IP:5000
  • 폰/아이패드는 같은 주소 열고 홈 화면에 추가
5

연결 확인

  • 허브 화면에 ESP32 '온라인', 센서값 1초마다 갱신
  • 폰에서 팬 ON → ACK와 지연(ms) 확인
  • 공유기를 껐다 켜서 자동 재접속 확인
  • Wi-Fi를 끊고 USB 백업으로 전환되는지 확인
